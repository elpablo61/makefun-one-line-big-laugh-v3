Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun: one funny line, 200 characters or fewer, that lands entirely on its own.

## The line (107 characters)

> I put my phone on silent for a funeral. It vibrated once. It was my mother, texting, 'Are you ignoring me?'

## How it works

`main.ts` writes that single line to `/output/entry.txt` (UTF-8, 1–200 characters, no trailing newline), which is what the judge reads.

```sh
node main.ts
```

## Calibration

Built against the 90 verified top-10 winning lines in `judge-calibration-one-liner.md`: one specific scene, a named detail (a funeral, a mother, her exact text), no explaining of the feeling or the punchline, one concept only — and the last sentence is a quoted fact, not a conclusion.
